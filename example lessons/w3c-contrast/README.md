# Colors with Good Contrast media fixture

This fixture uses the W3C Web Accessibility Initiative video [Colors with Good Contrast](https://www.w3.org/WAI/perspective-videos/contrast/) for the public Access demonstration. The standard and audio-described editions retain the complete source ending and are included under the reuse terms linked from the W3C source page.

## Review status

- `captions.en.vtt` and `captions-described.en.vtt` preserve the W3C English source captions and timing.
- `captions.am.vtt` and `captions.ti.vtt` were prepared from the supplied Hasab AI caption documents. Human Amharic and Tigrigna review is pending.
- `accessibility-prototype.pdf` is tagged and marked as a prototype. PDF/UA and screen-reader verification are pending.
- The generated BRF download is uncontracted English. Braille-transcriber review is pending.
- `ethsl.mp4` is intentionally absent. The player enables EthSL synchronization controls only when a consented recording is supplied; fluent interpreter and Deaf review remain required.

The MP3 files are 48 kbps mono extractions of the corresponding video tracks. Regenerate the PDF with `scripts/generate_accessible_pdf.py`. Source caption documents are retained for reviewer comparison and should not be represented as approved translations.
