# Savanna integration boundary

This directory is reserved for supported host mapping and adapters. The preserved static capture lives in `Savanna-static-pages/`, while the working public demonstration lives in `examples/savanna/` and uses the same Web Component/API as independent hosts.

The production adapter remains intentionally empty because ALX identity, enrollment, content, course-version, CSP and completion contracts are unconfirmed. Never implement authentication by reading captured body classes, cookies or form tokens from the fixture.
