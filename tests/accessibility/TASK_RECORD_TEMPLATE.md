# Anonymous participant task record

Template only: do not treat an empty record as conducted testing. Obtain participation consent and separate recording/publication permission. Do not record diagnoses, real learner identifiers, private credentials, voice/video or names in this repository.

| Participant's own device/tools | Pending |

| Outcome | Completed unaided / completed with help / blocked / stopped by participant |

Assess complete processes, including lost-network recovery, downloads and return focus. A participant may pause/stop without pressure. A stopped task is not participant failure; assisted completion is not unaided. Browser trees, automation and an agent's operation are not participant/AT evidence.
