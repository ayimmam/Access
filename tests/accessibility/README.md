# Accessibility evidence

Automated accessibility assertions currently live with the Playwright journeys in `tests/integration/` and `tests/vercel/`. The current result and criterion gaps are recorded in [`docs/WCAG_CONFORMANCE.md`](../../docs/WCAG_CONFORMANCE.md).

Store human keyboard, NVDA, TalkBack, zoom/reflow and co-design evidence here as it is collected. Do not convert an axe result or a developer keyboard check into a WCAG conformance claim.
