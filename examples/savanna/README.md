# savanna

Integrated example derived from, without altering, the supplied static captures.

Run the API after building the component, then open `/` or `/demo/savanna`. The Savanna-style course page uses the supplied ALX video and caption export with native video controls, searchable transcript, offline resources and an optional labeled 3D timing prototype. Sidebar collapse and session-only completion work independently of playback. See the [EthSL workflow](../../docs/architecture/SIGN_AVATAR_WORKFLOW.md) for reviewed avatar interpretation requirements.
